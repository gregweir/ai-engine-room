# AI Engine Room 0.1.1 release checklist

This checklist controls the first stable, unsigned release. Historical preview
records remain unchanged.

## Source gate

- [x] `package.json`, Tauri, and application Cargo versions are exactly 0.1.1.
- [x] The release source is merged to `main`, clean, and identified by complete
      commit and tree hashes.
- [x] Ordinary deterministic CI passes on Ubuntu and Windows.
- [x] Release notes, support, security, and safe-install guidance agree.

`4f4eef7ee05b12e5e3c6c6aaed162d13b5b654c7`, tree

## Exact artifacts

- [x] Build exactly one `.deb` on the verified Ubuntu 24.04 LTS x86_64 host.
- [x] Build exactly one NSIS installer on the verified Windows 11 x64 host.
- [x] Record exact filenames, byte sizes, and complete SHA-256 values.
- [x] Confirm package identity/version/architecture, licence payloads, and the
      expected unsigned state.
- [x] Create `SHA256SUMS.txt` containing only the two accepted packages.

## Physical acceptance

- [x] On each verified baseline, install the exact candidate through the normal
      operating-system flow without weakening security controls.
- [x] Confirm native launch, version 0.1.1 where exposed, core navigation,
      Refresh, Report, Copy, Save, and existing-file no-clobber behavior.
- [x] Close each application normally and confirm no application process or
      validation report artifact remains. The operator deliberately retained
      both 0.1.1 installations after normal removal passed in earlier bounded
      candidate testing.

## Publication

- [x] Create tag `v0.1.1` at the accepted source revision.
- [x] Create a non-prerelease GitHub Release using
      `v0.1.1-release-notes.md` as the reviewed basis.
- [x] Upload only the accepted `.deb`, NSIS installer, and `SHA256SUMS.txt`.
- [x] Independently download all three assets and recheck names, byte sizes,
      hashes, unsigned disclosure, support links, and release status.
- [x] Update the public Tartanleaf publisher page only after the GitHub release
      is verified.
