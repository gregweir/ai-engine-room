# Milestone 1X-E publisher-page publication-record contract

## Status

Developer-approved on 2026-08-31 for one bounded, documentation-only
reconciliation of the repository with the separately approved Tartanleaf
publisher-page publication.

## Purpose

Milestone 1X-E records that the official AI Engine Room publisher page and its
stable Tools-page route are now public. It closes the repository documentation
gap left after the website work and identifies the WinGet evidence that still
does not exist.

The website publication was separately approved and completed outside this
repository milestone. This contract records that external fact; it does not
retroactively treat the earlier planning documents as publication authority.

## Authorized work

This implementation authorizes only:

- this contract;
- one concise publisher-page publication and verification record;
- status corrections in the WinGet identity plan and historical publisher-page
  copy draft; and
- a roadmap update that records publication without overstating WinGet
  readiness.

The record may cite the public Tartanleaf page, the public Tools page, the
existing GitHub prerelease, and already tracked release evidence. It may not
change any of them.

## Required distinctions

The documentation must keep these facts separate:

- the publisher page and Tools-page route are publicly discoverable;
- the live CMS copy is authoritative and is not a byte-for-byte publication of
  the repository-local draft;
- the existing release remains a direct-download unsigned preview;
- no WinGet catalog entry, approved manifest, or package identifier exists;
- isolated unattended installation and removal remain unverified; and
- publication of a publisher page closes only the official-source
  discoverability gap.

## Explicit exclusions

This slice does not authorize:

- editing the Tartanleaf website or the GitHub prerelease;
- downloading, executing, installing, removing, rebuilding, repackaging,
  signing, or replacing an installer;
- creating or validating a WinGet manifest or installing WinGet tooling;
- forking or contributing to `microsoft/winget-pkgs`;
- reserving or approving `Tartanleaf.AIEngineRoom`;
- changing product, version, packaging, provider, inference, updater, CI, or
  release behavior; or
- claiming WinGet, signing, security, privacy, production, or broader-platform
  readiness.

## Acceptance criteria

This reconciliation is complete only when:

- the official product and Tools URLs are recorded;
- the record states what was verified at normal and narrow widths;
- the exact current preview identity remains linked to tracked release evidence;
- stale claims that the publisher page is unpublished are corrected;
- the remaining disposable-Windows and manifest gates stay explicit;
- repository readiness and formatting checks pass; and
- the diff remains limited to this contract and the four distribution/roadmap
  records named above.

## Subsequent gate

Completion authorizes no distribution action. The next possible WinGet gate is
one separately approved silent-install and removal verification against an
exact candidate in a supported disposable Windows environment. Manifest
authoring and external submission remain later, separate decisions.
