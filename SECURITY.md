# Security Policy

## Supported versions

AI Engine Room 0.1.1 is the currently supported stable release. Security
reports affecting 0.1.1 or the current default branch are relevant. The
historical `v0.1.0-preview.1` artifacts are no longer the current release.
AppImage packaging remains deferred and unsupported.

## Reporting a vulnerability

Email [gweir@tartanleaf.com](mailto:gweir@tartanleaf.com). Do not post sensitive vulnerability details, credentials, private machine data, or exploit material in a public issue.

Include only the information needed to understand and reproduce the issue safely. You may receive acknowledgement or follow-up questions. Maintenance is provided on a best-effort basis; no response or remediation SLA is guaranteed.

The project makes no bug-bounty, encryption, security-certification, or vulnerability-free claim. For ordinary usage questions and non-sensitive defects, see [SUPPORT.md](SUPPORT.md).
