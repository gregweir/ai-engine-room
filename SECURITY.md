# Security Policy

## Supported versions

AI Engine Room is work-in-progress pre-release software. No version is currently designated stable or supported for security maintenance as a generally released product. Reports affecting the current default branch and the local `.deb` verification build are relevant. AppImage packaging is deferred and is not part of the current verification contract.

## Reporting a vulnerability

Email [gweir@tartanleaf.com](mailto:gweir@tartanleaf.com). Do not post sensitive vulnerability details, credentials, private machine data, or exploit material in a public issue.

Include only the information needed to understand and reproduce the issue safely. You may receive acknowledgement or follow-up questions, but no response or remediation SLA is guaranteed.

The project makes no bug-bounty, encryption, security-certification, or vulnerability-free claim. For ordinary usage questions and non-sensitive defects, see [SUPPORT.md](SUPPORT.md).
